# Diffuse 0.12.1 — локализация и контроль безопасности

Дата: 2026-11-10 (+03:00)

## Результат

Windows-сборка теперь содержит собственный русский gettext-каталог Diffuse и
выбирает язык по системной локали Windows. Версия увеличена до 0.12.1, чтобы не
подменять уже опубликованный артефакт 0.12.0.

- Unittest: 13 успешно, 1 проверка симлинка штатно пропущена в Windows.
- Flake8 изменённых Python-файлов: успешно.
- Bandit по `packaging/windows`: 0 находок.
- Gitleaks по рабочему дереву: 0 утечек.
- Inno Setup: сборка завершена успешно.
- Установка с диска I: код завершения 0.
- Установлен `locale/ru/LC_MESSAGES/diffuse.mo`, 17 858 байт.
- Живое окно отвечает; заголовок: `Слияние Файлов 1 - Diffuse`.

## Остаточные риски

Установщик не подписан Authenticode, поэтому Windows SmartScreen может показать
предупреждение. Полный MyPy на Windows также показывает прежние замечания в
`src/diffuse/preferences.py` и `src/diffuse/utils.py`; изменённый launcher этих
ошибок не создаёт, а Linux CI остаётся обязательным релизным гейтом.
