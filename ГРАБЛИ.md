# Грабли проекта Diffuse

## Windows-сборка не включает перевод приложения

Симптом: в исходниках есть `po/ru.po`, GTK-компоненты частично переведены, но
интерфейс установленной Windows-версии остаётся английским. Причина: сборка
PyInstaller не компилировала и не включала домен `diffuse.mo`, а launcher не
задавал gettext-язык из локали Windows. Лечение: проверять `msgfmt --check`,
включать `locale/ru/LC_MESSAGES/diffuse.mo` в spec-файл и задавать `LANGUAGE`
до импорта приложения; подтверждать установленным каталогом и кириллическим
заголовком живого окна.

Обновлено: 2026-11-09 (+03:00)

## Оглавление

- MyPy проверяет тип pipe строже runtime
- setup-python внутри Flatpak container
- postinstall не должен предполагать необязательные каталоги

## MyPy проверяет тип pipe строже runtime

Симптом: локальные unittest/flake8 зелёные, CI MyPy падает на `chunks` и
`Popen.stdout`. Причина: пустой список не выводится при строгой проверке, а
`Popen.stdout` имеет общий тип `IO[bytes]`, не узкий `BinaryIO`. Лечение:
явный `List[bytes]` и контракт `IO[bytes]`; запускать MyPy до публикации.

## setup-python внутри Flatpak container

Симптом: privileged Flatpak job падает до сборщика с «Python 3.10 was not
found for org.freedesktop.platform 25.08». Причина: `actions/setup-python`
не публикует toolcache для этой container OS. Лечение: не запускать
setup-python в Flatpak SDK container; использовать системный Python runtime.
## postinstall не должен предполагать необязательные каталоги

Симптом: Flatpak собирает и устанавливает все файлы, затем падает на
`glib-compile-schemas /app/share/glib-2.0/schemas`. Причина: приложение не
устанавливает GSettings schemas, а hardening с `check=True` сделал прежнее
игнорирование ошибки видимым. Лечение: выполнять postinstall-утилиту только
когда соответствующий каталог действительно установлен.
