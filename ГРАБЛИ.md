## MyPy проверяет тип pipe строже runtime

Симптом: локальные unittest/flake8 зелёные, CI MyPy падает на `chunks` и
`Popen.stdout`. Причина: пустой список не выводится при строгой проверке, а
`Popen.stdout` имеет общий тип `IO[bytes]`, не узкий `BinaryIO`. Лечение:
явный `List[bytes]` и контракт `IO[bytes]`; запускать MyPy до публикации.

## setup-python внутри Flatpak container

Симптом: privileged Flatpak job падает до сборщика с «Python 3.10 was not
found for org.freedesktop.platform 25.08». Причина: `actions/setup-python`
не публикует toolcache для этой container OS. Лечение: не запускать
setup-python в Flatpak SDK container; использовать системный Python runtime.
